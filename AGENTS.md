# AGENTS.md

Architecture notes for AI agents and developers working on this codebase.

## Overview

A personal portfolio site for Ben Mwaniki: home/hero, resume (experience
+ education), projects, blog, and a contact form. Built with TanStack Start,
styled with Tailwind CSS 4 in a dark "luminous green" theme, deployed on
Netlify.

## Tech Stack

- **Framework**: TanStack Start (file-based routing via TanStack Router)
- **UI**: React 19, Radix UI primitives in `src/components/ui/`
- **Styling**: Tailwind CSS 4, theme tokens as CSS variables in `src/styles.css`
- **Content**: `@content-collections/core` — typed markdown collections defined in `content-collections.ts`
- **Forms**: Netlify Forms (see the Contact page notes below)
- **Language**: TypeScript, strict mode

## Directory Structure

```
content/
  jobs/         # work history — one file per role
  education/     # schools/programs — one file per entry
  projects/      # portfolio projects
  blog/          # blog posts
src/
  components/ui/ # Radix-based primitives (Card, Badge, HoverCard, Separator, Checkbox)
  routes/        # file-based routes (see below)
  styles.css     # theme tokens + global styles
public/
  contact.html   # static form skeleton — required for Netlify Forms detection, never shown to users
  headshot-on-white.jpg
content-collections.ts  # zod schemas for jobs/education/blog/projects
```

## Routes

| Path | File | Purpose |
|---|---|---|
| `/` | `src/routes/index.tsx` | Hero, skills grid, latest role/education snapshot |
| `/resume` | `src/routes/resume.tsx` | Full work history + education, pulled from content collections |
| `/projects` | `src/routes/projects.tsx` | Project grid from `content/projects` |
| `/blog` | `src/routes/blog/index.tsx` | Blog post list from `content/blog` |
| `/blog/$slug` | `src/routes/blog/$slug.tsx` | Individual post, matched on `_meta.path` |
| `/contact` | `src/routes/contact.tsx` | Contact form |

`src/routes/__root.tsx` holds the shared header/nav and footer and loads
Google Fonts (Bricolage Grotesque for display, IBM Plex Sans/Mono for body).

## Content Collections

Editing a resume, adding a job, or adding a blog post means adding/editing a
markdown file under `content/`, not touching route components — the routes
read from `allJobs`, `allEducations`, `allProjects`, `allBlogs` (generated by
content-collections from the matching directory + schema in
`content-collections.ts`).

## Contact Form (Netlify Forms)

TanStack Start renders the contact form client-side, so Netlify's build-time
form scanner never sees it directly. `public/contact.html` is a hidden static
duplicate of the form that exists solely so Netlify registers the `contact`
form name during the build. The real form in `src/routes/contact.tsx` submits
via `fetch('/contact.html', …)` with `application/x-www-form-urlencoded` —
posting to `/contact.html` (not `/`) is required so the request reaches
Netlify's forms middleware instead of being swallowed by the SSR handler.
If you change the form's field names, update both files together.

## Theme

Colors live as CSS custom properties in `src/styles.css` (`:root`/`.dark`,
both currently set to the same dark, green-tinted palette — there is no
light/dark toggle, the dark theme is the only theme). `--primary` is the
luminous green accent; utility classes `.glow-text` and `.glow-border` apply
the signature glow effect.

## Conventions

- Components: PascalCase. Routes: kebab-case files, following TanStack Router file conventions.
- Import paths use the `@/` alias for `src/`.
- Tailwind utility classes directly in JSX; `cn()` (`src/lib/utils.ts`) for conditional merges.
- Zod schemas in `content-collections.ts` are the source of truth for markdown frontmatter shape.

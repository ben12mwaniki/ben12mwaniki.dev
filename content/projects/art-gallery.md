Built a secure full-stack web application using Spring Boot to support artwork
management, user interactions, and online sales workflows. Designed RESTful APIs
and integrated Vue.js and Android frontends to provide multiple client
experiences over a shared backend.

Translated user requirements into domain models and structured PostgreSQL
database schemas, applying object-oriented design principles to create a
scalable and maintainable application architecture.

Implemented automated unit and system testing with JUnit and integrated tests
into a CI pipeline using Travis CI to validate application functionality and
improve development reliability.

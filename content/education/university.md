Capstone project involved designing a full‑stack gallery management system built with Java Spring Boot for the backend and Vue.js for the web frontend. The platform enables artists to showcase and sell artwork while allowing customers to browse, purchase, and interact with creators. Development followed Agile methodology with iterative sprints and applied Test‑Driven Development (TDD) to ensure reliability and maintainability. Alongside the web application, an Android client was implemented to provide essential features for mobile users. The project covered requirements gathering, system architecture design, implementation, testing, and deployment of a multi‑tier solution suitable for real‑world use.
